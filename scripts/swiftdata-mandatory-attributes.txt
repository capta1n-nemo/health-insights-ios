# Mandatory (non-optional, no default) stored properties on shipped @Model types.
#
# This repo has NO SchemaMigrationPlan and relies on SwiftData's implicit
# lightweight migration, which CANNOT fill a new mandatory column. Adding one to
# a shipped model makes the store fail to migrate, and DataStore.init turns that
# into a fatalError — the app dies on launch for every existing install. That
# shipped on 2026-08-09 (189a5e1, LabResultRecord.shapeRaw) and the reader hit it
# within minutes.
#
# ⚠️ A fresh simulator install CANNOT reproduce it: with no store to migrate,
# broken and fixed builds both launch. Only a device with history fails.
#
# Everything below shipped together and is therefore safe. verify.sh fails on any
# NEW entry. If you are adding a stored property to a @Model: make it optional,
# or give it a default. There is no third option here.
